Research · manuscript in preparation

      
Catching people who try to steal a model through its API

      

        

          
If you can query a model enough times, you can train a copy of it. My paper proposes a wrapper that sits in front of an LLM API and watches the shape of each user's questions. Normal users ask clustered, purposeful questions; extraction attacks sweep the whole space.

          
    
            
  • Compares each session's query embeddings to normal traffic with maximum mean discrepancy (MMD).
    • 
            
  • Needs only normal traffic to calibrate, no attack examples.
    • 
            
  • Responds in five graduated levels, so legitimate users aren't punished for one odd query.
    • 
            
  • Benchmarked against PRADA, SEAT and other defenses on 14 extraction scenarios.
    •
